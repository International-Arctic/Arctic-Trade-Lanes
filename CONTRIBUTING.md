# Contributing

- **Additive only** — do not smash App.tsx, do not full-SPA redeploy for cosmetic i18n, do not GREEN no-op passes.
- Prefer verified sources (≥2, one official/institutional) for any dataset row.
- Never commit API keys, Cloudflare tokens, Bankr secrets, or private passport/KYC material.
- Zo remains the production control plane; PRs here should improve docs, samples, and schemas first.
