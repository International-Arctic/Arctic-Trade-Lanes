# Contributing

Thanks for helping build open Arctic GIS that ships commercially without political bias.

## Rules

- **Additive only** — do not smash App.tsx, do not full-SPA redeploy for cosmetic i18n, do not GREEN no-op passes.
- Prefer verified sources (≥2, one official/institutional) for any dataset row.
- Never commit API keys, Cloudflare tokens, Bankr secrets, or private passport/KYC material.
- Zo remains the production control plane; PRs here should improve docs, samples, schemas, and client-side filters first.
- Live product: [arctictradelanes.com](https://arctictradelanes.com) · Collaborate: [/collaborate](https://arctictradelanes.com/collaborate)

## Good first contributions

1. Client-side bad-geo filter (see `docs/CLIENT-GEO-FILTER.md`)
2. EPSG:3996 projection QA for ships/ports layers
3. Port / ship attribute completeness against public registries
4. Cheap static/vector-tile serving notes (no paid GIS SaaS required)

Open an Issue with label ideas if unsure. Be concrete and source-linked.

## Community

We welcome OSS engineers interested in **Arctic mapping, NSR / Polar Silk Road logistics GIS, polar projections, and open maritime data**. Please use GitHub Issues/Discussions on this org — keep discourse technical and politically neutral.
